# Avoid AI Writing RU

Русскоязычная адаптация [Avoid AI Writing](https://github.com/conorbronsdon/avoid-ai-writing)
Conor Bronsdon: редактура русских текстов с сохранением фактов, ссылок
и авторской манеры. Включает дипломы, ВКР, курсовые, диссертации,
рефераты, отчёты и научные статьи.

Это самостоятельная локализация инструкций и редакторского каталога,
а не русский перевод интерфейса английского детектора. Она сохраняет
режимы и основные редакторские ограничения оригинала, адаптирует
категории к русскому и добавляет академический профиль. Это не полная
локализация программного репозитория upstream: его плагины, английский
детектор, английские тесты и английские style-checkers сюда не перенесены.
Вместо них поставляется небольшой независимый русский сканер кандидатов
и консервативный валидатор сохранности. Основной аудит делает агент.

## Что умеет

- Проверять без правок (`detect`), переписывать (`rewrite`) или точечно
  редактировать файл (`edit`).
- Находить пустые вступления, рекламные усилители, канцелярит,
  синонимическую карусель и логически пустые выводы.
- Учитывать контекст и авторский голос, не навязывая разговорность.
- Беречь цитаты, формулы, числа, таблицы, библиографию и научные ограничения.
- Помогать писать новые академические разделы по реальным материалам,
  не выдумывая исследование, источники и результаты.
- Проверять результат с лимитом до двух изменяющих проходов.

Скилл не определяет авторство, не измеряет «процент ИИ», не проверяет
плагиат и не обещает прохождения университетских систем контроля.
Русские эвристики не валидированы на репрезентативном корпусе.

## Установка

Скопируйте папку репозитория целиком, а не один SKILL.md: каталог
и академические правила находятся в references/.

Для Codex (PowerShell):

```powershell
git clone https://github.com/kzhigalov-dev/avoid-ai-writing-ru.git "$env:USERPROFILE/.codex/skills/avoid-ai-writing-ru"
```

Для Claude Code используйте папку `~/.claude/skills/avoid-ai-writing-ru`.
В других агентах поместите папку в поддерживаемую ими директорию
Agent Skills. Изменения глобальных настроек не требуются.

## Примеры запросов

```text
Используй $avoid-ai-writing-ru. Убери ИИ-штампы из текста, сохрани мой голос.

Проверь введение курсовой без правок. Укажи, где не хватает источников.
--mode detect --context coursework

Отредактируй главу диплома на месте: draft.md. Не меняй план, ссылки и числа.
--mode edit --context thesis --voice academic --iterate 2

Напиши обсуждение по приложенным результатам и источникам.
Не добавляй новых эмпирических утверждений.
```

Параметры выше являются подсказками агенту, а не командой терминала.

## Локальные проверки

Python 3.10+, без сторонних пакетов:

```bash
python scripts/check.py scan draft.md --context thesis
python scripts/check.py preserve before.md after.md
python -m unittest discover -s tests -v
```

Вывод JSON. Коды завершения: 0 — кандидатов/механических отличий нет;
1 — они есть; 2 — ошибка. Обе команды только читают файлы UTF-8
(.md, .markdown, .txt). DOCX и PDF напрямую не поддерживаются.

Сканер реализует лишь небольшой поднабор каталога. Кандидат требует
чтения контекста; валидатор не устанавливает смысловую эквивалентность.
Нормализация кавычек и проверка пользовательского style-файла
выполняются моделью, а не отдельными автоматическими командами.
